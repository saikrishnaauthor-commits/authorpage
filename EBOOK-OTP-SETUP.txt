BEFORE DEPLOYING
----------------
1. Keep the three PDFs private in Google Drive. Do not enable "Anyone with the link".
2. In Google Cloud Console:
   - Create/select a Google Cloud project.
   - Enable the Google Drive API.
   - Create a service account and generate a JSON key.
   - Copy the service account's client_email.
   - Share EACH of the three PDF files with that client_email as Viewer.
3. In Render > your existing web service > Environment, add:
   GOOGLE_SERVICE_ACCOUNT_JSON = the complete service-account JSON contents
   (paste the JSON as one value; keep it private).
   OTP_SECRET = a long random secret (recommended)
   SESSION_SECRET = a different long random secret (recommended)
   Existing SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, MAIL_FROM must be valid
   so OTP emails can be delivered.
4. Do not commit .env, service-account JSON, SMTP credentials, or any secrets to GitHub.
5. Commit/push these updated files to the same GitHub repository used by Render and
   allow Render to redeploy. The Vercel site must deploy the updated index.html and js/ebooks.js.
6. Test with an email that has a successful/paid order containing one of the E-Book
   product IDs (book_1_eb, book_2_eb, book_3_eb). Paperback-only purchases do not grant
   e-book access. Use a real OTP sent by email.

IMPORTANT SECURITY NOTES
------------------------
- Access is checked server-side against paid MongoDB orders each time the library or PDF
  endpoint is requested. Google Drive file IDs are only stored in the backend.
- The reader does not show a PDF download link or download button. However, once pages
  are rendered in a customer's browser, no web implementation can absolutely prevent
  screenshots or a technically capable user from extracting content delivered to that
  browser. This is access control and download deterrence, not DRM.
- OTP emails are valid for 10 minutes, have a 5-attempt limit, and are throttled to one
  request per minute per email.
- The reader session is stored in sessionStorage and expires after 12 hours.
- Google service-account JSON must be pasted into Render environment settings only,
  never into frontend files or Git.

If a Drive file fails to load, check that Drive API is enabled and the service-account
email has Viewer access to that exact file.
